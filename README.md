# Tallowwood Carpentry: concept website

A concept website by [Mago Labs](https://magolabs.in) for a fictional carpenter in Bangalow, NSW. Tallowwood Carpentry is not a real business: the name, logo, owner, phone number, address, projects and quotes are invented, and the photos are stock images from Unsplash.

Plain HTML, CSS and vanilla JS, no build step. Fonts self-hosted.

- `index.html` and `projects/`: homepage and five project stories
- `styles.css`, `site.js`: styles and behaviour (timber index, sticky process story, project planner, photo lightbox)
- `js/motion.js`: scroll progress, count-ups, tilt, ripple, parallax
- `js/fx3d.min.js`: WebGL 3D timber frame that assembles itself in the hero (three.js, loaded after first paint)
